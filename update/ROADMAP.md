# Roadmap — pdfia_v0.1

But du projet
- Offrir une solution simple pour ... (décrire brièvement l'objectif principal).
- Prioriser la stabilité, l'expérience utilisateur et l'automatisation des traitements PDF.

Principales directions pour les prochaines versions
1. Version 0.2 — Améliorations immédiates (1–2 sprints)
   - Correction des bugs critiques reportés.
   - Amélioration de l’UX sur l’interface web (CSS/HTML).
   - Meilleure gestion des fichiers volumineux et optimisation mémoire.
2. Version 0.3 — Fonctionnalités (2–4 sprints)
   - Ajout de l’export en plusieurs formats.
   - Filtrage et recherche avancée dans les PDF.
   - Ajout d’un pipeline d’upload asynchrone.
3. Version 1.0 — Stabilisation & release majeure
   - Tests automatisés couvrant les flux principaux.
   - Documentation utilisateur complète.
   - Politique de versionnement et compatibilité ascendante.
4. Au-delà de 1.0
   - Internationalisation (i18n).
   - API publique documentée.
   - Intégrations (ex. stockage cloud, OCR amélioré).

Comment se matérialise la roadmap
- Chaque item doit avoir une issue associée et être planifié dans un milestone.
- Prioriser tickets par criticité (P0, P1, P2).
- Réunions de planning = fin de sprint (bi‑hebdomadaire recommandé).
